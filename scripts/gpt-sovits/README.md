# GPT-SoVITS Conversion & Quantization Scripts

Place conversion scripts (e.g., PyTorch to GGUF) and quantization scripts in this directory.

## Expected Models

- **CNHubert**: Feature extraction model (`cnhubert.py` / `cnhubert.gguf`)
- **BERT**: Chinese RoBERTa WWM Ext Large model (`bert.py` / `bert.gguf`)
- **T2S (Text-to-Semantic)**: GPT autoregressive stage (`t2s.py` / `t2s.gguf`)
- **VITS**: Acoustic decoder & generator (`vits.py` / `vits.gguf`)
