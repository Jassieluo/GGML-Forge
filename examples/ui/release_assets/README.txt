GGML-Forge Studio Preview
=========================

启动
----
双击 bin\ui-demo.exe。
侧栏“外观与语言”区域可在中文和 English 之间即时切换。

主要演示
--------
- Qwen3.5 本地流式对话及图片附件
- GPT-SoVITS Q4 语音合成、预置音色选择和自定义参考 WAV
- whisper.cpp Q4 WAV 语音识别与翻译
- SDXS Q4 文本生成图片
- YOLOv8 分类、检测、实例分割、姿态和 OBB
- 语义分割与双目深度估计

运行后端
--------
- CPU：无需独立显卡。
- CUDA：需要兼容的 NVIDIA 显卡和驱动。
- SYCL：需要兼容的 Intel 显卡和驱动。首次运行可能需要较长时间准备内核。
- Whisper 演示当前固定使用已验证的 CPU 路径；其他页面遵循 UI 中选择的后端。

模型和输出
----------
- 模型位于 models\，UI 只展示本包收录的演示模型。
- 生成结果写入 outputs\ui-demo\。
- SYCL 临时缓存位于 bin\cache\sycl\。当前默认关闭不稳定的持久化 JIT 缓存。

语音合成参考 WAV
----------------
导入自定义 WAV 后，必须填写音频中实际说出的准确文字。参考文字与音频不一致会明显影响音色和发音。
建议使用干净、单人、无背景音乐的短音频；程序会自动将 WAV 混合为单声道。

模型精度说明
------------
发布包中的主要推理权重均为 Q4。Qwen 多模态视觉投影文件 mmproj-F16.gguf
是当前图片输入所必需的配套文件，目前没有 Q4 版本，因此它是唯一保留的 F16 模型组件。

已知事项
--------
- 不同显卡驱动对 CUDA/SYCL 的兼容性不同；遇到问题时可切换为 CPU。
- SYCL 首次推理可能明显慢于后续推理。
- Microsoft Visual C++ x64 Redistributable 需要由系统安装。
